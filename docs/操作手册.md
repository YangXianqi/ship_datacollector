# 船厂离线采集平台操作手册

## 1. 文档说明

本文档用于说明当前项目的安装、启动、后台配置、安卓端使用方法和常见问题处理方式。

当前系统由 3 部分组成：

- 安卓采集端：工人用于离线采集、缓存、续传、清理缓存
- 后端服务：提供登录、权限、上传、断点续传、上传确认等接口
- 管理后台：管理员按手机号创建账号、分配表单权限、控制上传权限和清缓存权限

注意：

- 当前版本除“真氚云接入”外，其余主流程已基本打通
- 当前上传成功是以“后端当前网关确认成功”为准
- 真正接入氚云后，还需要再联调一次氚云鉴权、字段映射和回执确认

## 2. 适用场景

- 工地现场网络较差，先采集，后上传
- 不同手机号对应不同表单入口
- 需要拍照、语音备注、文字备注
- 上传失败后保留本地缓存，后续继续上传

## 3. 默认账号与地址

### 3.1 默认账号

- 管理员账号：`13900000000 / admin123`
- 工人测试账号：`13800000000 / worker123`

### 3.2 默认端口

- 后端接口：`http://localhost:8080/api`
- 管理后台开发地址：`http://localhost:5173`

- JDK 17

项目结构如下：

```text

```

## 5. 启动步骤

## 5.1 启动本地 PostgreSQL

在项目根目录执行：

```bash
./scripts/start-local-postgres.sh
```

如果后端要直接使用项目内准备好的 PostgreSQL 环境变量，执行：

```bash
source ./scripts/backend-postgres-env.sh
```

停止本地 PostgreSQL：

```bash
./scripts/stop-local-postgres.sh
```

## 5.2 启动后端

在项目根目录执行：

```bash
source ./scripts/backend-postgres-env.sh
/home/sm6/project/.tools/gradle-8.7/bin/gradle -Djava.io.tmpdir=/home/sm6/project/.tmp -p /home/sm6/project/backend bootRun --no-daemon
```

启动成功后，后端默认监听：

`http://localhost:8080`

## 5.3 启动管理后台

进入后台目录执行：

```bash
cd /home/sm6/project/admin-web
npm run dev
```

浏览器访问：

`http://localhost:5173`

如果需要显式指定后端地址：

```bash
cd /home/sm6/project/admin-web
VITE_API_BASE_URL=http://localhost:8080/api npm run dev
```

## 5.4 编译安卓端

进入安卓项目目录执行：

```bash
cd /home/sm6/project/android-app
/home/sm6/project/.tools/gradle-8.7/bin/gradle -Djava.io.tmpdir=/home/sm6/project/.tmp :app:assembleDebug --no-daemon
```

已验证可编译通过。

APK 默认输出路径：

`android-app/app/build/outputs/apk/debug/app-debug.apk`

## 6. 管理后台使用说明

## 6.1 管理员登录

1. 打开后台页面 `http://localhost:5173`
2. 输入管理员账号 `13900000000`
3. 输入密码 `admin123`
4. 点击“登录后台”

## 6.2 新建账号

1. 在右侧“新建账号”区域填写手机号
2. 填写姓名
3. 设置初始密码
4. 选择该账号可见的表单
5. 按需勾选以下权限：
- 启用账号
- 管理员
- 允许上传
- 允许删除缓存
6. 点击“保存账号”

说明：

- 工人账号通常不需要勾选“管理员”
- 如果不勾选“允许上传”，该账号只能采集，不能上传
- 如果不勾选“允许删除缓存”，该账号不能删除本地缓存

## 6.3 修改账号权限

1. 在左侧“账号列表”选择一个账号
2. 在“编辑权限”区域修改：
- 可用表单
- 是否管理员
- 是否允许上传
- 是否允许删除缓存
3. 点击“保存权限”

## 6.4 重置密码

1. 在“账号列表”中选中目标账号
2. 在“编辑权限”区域底部输入新密码
3. 点击“重置密码”

## 7. 安卓端使用说明

## 7.1 登录

1. 打开安卓 APP
2. 输入手机号
3. 输入密码
4. 点击“登录”

说明：

- 首次登录必须联网
- 登录成功后，30 天内允许离线继续使用最近一次登录账号

## 7.2 首页说明

首页会显示以下统计：

- 待上传
- 上传中
- 上传失败
- 已上传

首页还会显示：

- 当前登录手机号
- 离线有效期
- 当前账号权限
- 当前上传状态

首页有两个主要入口：

- 采集数据
- 上传数据

## 7.3 采集数据

### 7.3.1 进入采集页

1. 点击“采集数据”
2. 选择要采集的表单
3. 进入采集界面

### 7.3.2 采集内容要求

每条记录包括：

- 位置 / 部位名称：必填
- 图片：至少 1 张，最多 5 张
- 语音备注：可选，最多 1 条，最长 60 秒
- 文字备注：可选，最多 200 字

### 7.3.3 图片采集方式

支持以下方式：

- 拍照
- 从相册导入

### 7.3.4 图片预览与编辑

当前版本支持：

- 预览图片
- 左转 90°
- 右转 90°
- 居中裁剪
- 相册替换
- 重拍替换
- 删除图片

说明：

- 删除图片前会弹出确认框
- 图片编辑操作会直接作用于本地真实文件

### 7.3.5 语音备注

1. 点击“录音”
2. 开始录制
3. 再次点击按钮停止录音
4. 语音会保存到本地缓存

说明：

- 当前只支持 1 条语音备注
- 删除语音前会弹出确认框

### 7.3.6 预览并保存

1. 录入完内容后，点击“预览附件”
2. 检查位置、图片、语音、文字备注是否正确
3. 点击“保存并退出”

保存成功后：

- 数据先进入本地缓存
- 不要求现场网络可用

## 7.4 编辑本地记录

1. 进入某个表单下的本地记录列表
2. 找到状态为“待上传”或“上传失败”的记录
3. 点击“编辑”
4. 修改图片、语音、文字备注
5. 再次保存

说明：

- 已上传记录默认不再支持编辑

## 7.5 上传数据

### 7.5.1 进入上传页

1. 点击“上传数据”
2. 选择要上传的表单
3. 进入上传界面

### 7.5.2 上传页功能

上传页支持：

- 查看待上传、已上传数量
- 勾选记录
- 开始上传
- 暂停上传
- 继续上传
- 取消批次
- 删除选中的本地记录
- 清理已上传缓存

### 7.5.3 上传规则

- 上传默认手动触发
- 上传失败的记录继续保留在本地
- 后续网络恢复后，可以再次点击“继续上传”或“开始上传”
- 上传使用前台服务，可以在后台持续执行

### 7.5.4 断点续传

当前版本支持文件级断点续传：

- 上传中断后，未完成的文件会保留进度
- 恢复上传时，会从已确认的偏移位置继续

### 7.5.5 上传成功确认

上传成功后会看到：

- 记录状态变成“已上传”
- 页面或通知提示上传成功

注意：

- 已上传记录不会自动删除
- 需要人工勾选后点击“清理已上传”

### 7.5.6 删除与清缓存

为了避免误操作，以下动作都带确认框：

- 删除选中的本地记录
- 清理已上传缓存
- 取消当前上传批次

说明：

- “删除选中”会删除本地记录及其本地附件
- “清理已上传”只删除本地缓存，不影响后台已成功数据

## 8. 一条完整业务流程示例

以下是推荐演示流程：

1. 管理员在后台创建工人账号，并分配表单权限
2. 工人在安卓端登录
3. 点击“采集数据”
4. 选择表单
5. 填写位置 / 部位名称
6. 拍 1 到 5 张照片
7. 录制一条语音备注
8. 输入文字备注
9. 点击“保存并退出”
10. 在弱网或断网状态下先保留本地缓存
11. 网络恢复后进入“上传数据”
12. 勾选记录并点击“开始上传”
13. 若中途网络中断，则稍后点击“继续上传”
14. 上传成功后，记录变为“已上传”
15. 勾选已上传记录，点击“清理已上传”

## 9. 常见问题

## 9.1 登录失败

可能原因：

- 手机号或密码错误
- 后端未启动
- 首次登录时网络不可用
- 当前账号被后台禁用

排查建议：

- 先确认后端 `8080` 端口是否正常
- 确认账号是否存在
- 确认管理员是否关闭了该账号

## 9.2 无法上传

可能原因：

- 当前账号没有“允许上传”权限
- 当前网络不可用
- 当前表单下没有待上传缓存

排查建议：

- 后台检查该手机号是否勾选“允许上传”
- 检查手机是否联网
- 确认是否已经选择了正确表单

## 9.3 无法删除缓存

可能原因：

- 当前账号没有“允许删除缓存”权限

排查建议：

- 进入后台，给该账号开启“允许删除缓存”

## 9.4 新记录无法保存

可能原因：

- 没填写位置 / 部位名称
- 没有至少 1 张图片
- 本地缓存已达到 500 条上限

排查建议：

- 补全必填项
- 上传或删除一部分历史缓存后再继续采集

## 9.5 上传后为什么本地记录还在

这是当前系统的设计行为。

原因：

- 上传成功后，本地缓存不会自动删除
- 目的是让用户人工确认后再清理，避免误删

处理方式：

- 勾选“已上传”记录
- 点击“清理已上传”

## 11. 当前已知限制

以下内容目前仍是已知限制：

- 真实氚云接口尚未接入，当前仍是后端模拟网关
- 预览采用采集页内展开方式，不是单独新页面
- 目前图片裁剪为“居中裁剪”，不是自由框选裁剪
- 当前文档主要面向本地部署和联调环境，正式生产部署参数还需单独整理

## 12. 建议的现场使用方式

建议按以下方式落地使用：

1. 先由管理员为每个班组或工人创建手机号账号
2. 按岗位配置表单权限
3. 工人在有网环境下首次登录
4. 现场弱网环境只负责采集和保存
5. 回到网络较好的区域后，统一进入上传页执行上传
6. 确认成功后，再清理已上传缓存
